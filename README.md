# TravelFun

Desktop application for managing theme park visits and accommodation bookings, built with Java Swing.

## Features
- **Browse catalog**: explore available theme parks and accommodation options
- **Make reservations**: book accommodation linked to theme park visits
- **Discount game**: flip cards for a chance to win discounts on your next booking
- **Built-in help system**: integrated JavaHelp documentation

## Tech Stack
- Java SE
- Swing (GUI)
- JavaHelp
- File-based data persistence (.dat files)

## How to Run
1. Clone the repository
2. Open in Eclipse as an existing project
3. Add `lib/jhall.jar` to the build path if not detected automatically
4. Run `src/app/Main.java`
